# Urban Platter — Home Page, Steel Blue Glass redesign (Design 4)

A standalone Vite + React landing page. Same content as
https://urbanplatter.com/, completely new Steel Blue glass design.

This is Design 4, for branch `design-4`. Design 1 (Minimal Premium,
All collections page) stays on `main`, Design 2 (Dark Modern, home
page) stays on `design-2`, and Design 3 (Luxury Gold, home page)
stays on `design-3` in srijanlemmecode/Urban-Platter-Design1.
All are untouched here.

Design: Steel Blue — icy blue #EAF0F6, steel #8FA8BC, deep
navy-grey #1B2A3A, accent #33506B, Fraunces serif headings,
Inter body. Frosted glass throughout: translucent panels with
backdrop blur, soft gradient background, gentle shadows.

Cart: redesigned with a proper cart logo (SVG shopping bag in a
steel-blue circle), glass drawer, product photos in every line,
and a Proceed to Checkout button.

Animations included from the start: shimmering promo bar, hero
slow zoom + crossfade, sections glide up on scroll, product cards
stagger in and lift on hover, tiles pop, active hero dot glows,
bag drawer slides in, reduced-motion respected.

Content is real, from the live home page on 21 Nov 2026:
- 6-slide hero with real banner images, text in a compact strip below
  the image so it never overlaps the banner's own text
- Welcome / Trending: 8 products with real prices, MRPs, discounts, ratings and units bought
- Chini Kam banner + sugar calculator (live page formula: 1 tsp = 4 g = 16 kcal)
- Shop the Best: 6 products with real prices and images
- Shop By Lifestyle / Cuisines, Gifting, customer reviews, 6 FAQs, footer
- Promo: Get 10% OFF on orders above ₹2,500/-; free shipping above Rs. 500 (per FAQ)

## Run it locally

```bash
npm install
npm run dev
```

Then open the local URL Vite prints, usually http://localhost:5173

## Build

```bash
npm run build
npm run preview
```

Requires Node 18+. Do NOT push yet — Srijan wants to view it first.
