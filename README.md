# Urban Platter — Home Page, Luxury Gold redesign (Design 3)

A standalone Vite + React landing page. Same content as
https://urbanplatter.com/, completely new Luxury Gold design.

This is Design 3, for branch `design-3`. Design 1 (Minimal Premium,
All collections page) stays on `main` and Design 2 (Dark Modern,
home page) stays on `design-2` in
srijanlemmecode/Urban-Platter-Design1. Both are untouched here.

Design: ivory #F7F3EA, deep green #1E3D2F, gold #C9A227, Fraunces
serif headings, Inter body, thin gold rules, elegant white cards.

Content is real, from the live home page on 21 Nov 2026:
- 6-slide hero with real banner images, text in a compact strip below
  the image so it never overlaps the banner's own text
- Welcome / Trending: 8 products with real prices, MRPs, discounts, ratings and units bought
- Chini Kam banner + sugar calculator (live page formula: 1 tsp = 4 g = 16 kcal)
- Shop the Best: 6 products with real prices and images
- Shop By Lifestyle / Cuisines, Gifting, customer reviews, 6 FAQs, footer
- Promo: Get 10% OFF on orders above ₹2,500/-; free shipping above Rs. 500 (per FAQ)

## Run it locally

```bash
npm install
npm run dev
```

Then open the local URL Vite prints, usually http://localhost:5173

## Build

```bash
npm run build
npm run preview
```

Requires Node 18+. Do NOT push yet — Srijan wants to view it first.
